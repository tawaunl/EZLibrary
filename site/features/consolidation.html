Library Consolidation Shipped

Pull music scattered across drives and folders into one place, without breaking a single crate.

Most libraries end up spread across a Downloads folder, two external drives, an old Music folder and a desktop folder called new. That is fine until a drive is not plugged in, or you try to back the whole thing up.

Consolidation maps where your files actually are, moves or copies them into one destination, and rewrites every Serato path as it goes — so nothing goes missing on the way.

What it does

  • See the sprawl. Every source folder your library references, with how many tracks and how much data sits in each.
  • Choose what to pull in. Select source groups individually. You do not have to consolidate everything at once.
  • Move or copy. Move for a genuine consolidation, copy to build a second complete library.
  • Capacity checked first. The destination is validated against the size of what you selected before anything moves.
  • Paths rewritten as it goes. Serato's library, plain crates and smart crates are all updated so references stay valid.
  • Identity preserved. Library rows are re-pointed rather than recreated, so cues, beat grids and play counts stay attached.

How to use it

  1. Back up

    This one moves real audio files. Take a full backup first.

  2. Map your sources

    Run the scan and look at the source groups it found.

  3. Pick a destination

    Choose the folder everything should live in, and check the capacity estimate.

  4. Select and run

    Choose the source groups to pull in, run it with Serato closed, then reopen Serato and spot-check a few crates.
