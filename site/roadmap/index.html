Honest answers

How this board actually works

Votes matter, but they aren't a queue

Vote count is the strongest signal for what gets picked up next, and it's the reason the first column is sorted the way it is. It isn't the only input though. Anything that risks losing or corrupting a library gets fixed ahead of everything on this board, no matter how few votes it has.

Some things are genuinely hard

A few of the most-wanted items — Rekordbox transfer especially — mean reverse-engineering someone else's file format and keeping up with it as it changes. Those are scheduled deliberately late, not because nobody wants them, but because shipping them badly is worse than not shipping them.

Nothing here is a promise

This is a free project maintained by one person. The board is what's intended, in the order it's intended, and it's kept honest — but there are no dates on it and nothing on it is a commitment. What did ship is in the changelog, with the detail.

You can also just build it

It's GPLv3, and pull requests are welcome — from a typo fix upward. The contributing guide covers how to get set up, and the engineering rules cover what a change has to hold up to before it lands.
